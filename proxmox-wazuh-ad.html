Project Summary

Built, recovered, and validated a multi-VM cybersecurity lab on Proxmox VE behind a pfSense-segmented network. The project progressed from virtualization and network recovery into centralized Wazuh monitoring, Active Directory security-event validation, File Integrity Monitoring, SOC-style event correlation, and privileged Domain Admins membership monitoring.

October 1 — Proxmox Build and VM Foundation

  • Deployed Proxmox VE on dedicated hardware and integrated it with the isolated 192.168.10.0/24 cybersecurity lab network.
  • Created and configured Ubuntu Server, Kali Linux, Wazuh Server, and Windows Server 2022 virtual machines.
  • Established the base architecture for Windows, Linux, SIEM, and Active Directory testing.

October 2–3 — Network Recovery and Wazuh Integration

  • Diagnosed a Proxmox connectivity failure where the host became unreachable even though its static address and route remained configured.
  • Identified that the physical NIC was missing from the live vmbr0 Linux bridge.
  • Restored the interface, reattached it to vmbr0, reloaded networking, and verified the repair survived reboot.
  • Validated gateway, Internet, and VM-to-VM communication after recovery.
  • Verified Wazuh Manager, Indexer, and Dashboard services and enrolled Windows, Windows Server, Ubuntu, and Kali endpoints.
  • Confirmed Windows security-event collection, including failed-logon alerting from Windows Server 2022.

Windows File Integrity Monitoring

Configured real-time Windows File Integrity Monitoring using a dedicated test directory and verified both file creation and checksum-change activity in Wazuh.

  • Rule 554 — file added
  • Rule 550 — integrity checksum changed
  • MD5, SHA1, and SHA256 integrity data captured for validation.

SOC-Style Investigation

A controlled account-lockout scenario was used to correlate repeated failed authentication attempts with the resulting lockout event.

Investigation chain: 4625 → 4625 → 4625 → 4740

Wazuh was used to review the target account, source system, timestamps, rule IDs, severity, and Windows Security event context. The activity was confirmed as authorized lab testing.

A controlled account named PrivTest was temporarily added to the Domain Admins group and then removed. Wazuh captured both membership changes and exposed the changed member, privileged target group, administrative actor, and domain controller.
