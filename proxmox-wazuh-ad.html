Proxmox Cybersecurity Home Lab

Virtualization • Wazuh SIEM/XDR • Windows Server • Active Directory • Network Troubleshooting • SOC Investigation

Project Summary

Built and troubleshot a multi-VM cybersecurity lab on Proxmox VE behind a pfSense-segmented network. The environment centralizes Windows and Linux systems, Wazuh security monitoring, Active Directory services, File Integrity Monitoring, and controlled SOC-style event investigations.

Proxmox VEpfSenseWazuhWindows Server 2022Active DirectoryUbuntuKali Linux

Environment

  • Proxmox VE host on the isolated 192.168.10.0/24 cybersecurity lab network
  • Dedicated Wazuh Manager, Indexer, and Dashboard VM
  • Windows Server 2022 Domain Controller with AD DS and DNS
  • Ubuntu Server and Kali Linux endpoints
  • Windows endpoint monitoring through Wazuh agents

Key Accomplishments

  • Diagnosed a Proxmox connectivity failure caused by the physical NIC being absent from the live vmbr0 bridge.
  • Restored host and VM networking, reloaded the saved configuration, and verified the repair survived a reboot.
  • Validated gateway, Internet, and VM-to-VM connectivity across the lab.
  • Enrolled Windows, Windows Server, Ubuntu, and Kali endpoints into Wazuh.
  • Configured real-time Windows File Integrity Monitoring and verified file creation and checksum-change alerts.
  • Validated Active Directory authentication and account-management events in Wazuh.
  • Created a reusable Windows Server / AD security-event monitoring view.
  • Performed a mini SOC investigation correlating repeated failed logons with an account lockout.

SOC Investigation Example

A controlled test account was configured with a temporary lockout policy. Three failed authentication attempts generated Event ID 4625 events followed by Event ID 4740. Wazuh was used to review the target account, timestamps, source system, rule IDs, and severity.

Assessment: Authorized lab activity. No malicious activity identified. The account was unlocked after validation and temporary test objects were removed.
