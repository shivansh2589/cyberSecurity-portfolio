Proxmox Cybersecurity Home Lab

Virtualization • Wazuh SIEM/XDR • Windows Server • Active Directory • Privileged Group Monitoring • SOC Investigation

Project Summary

Built and troubleshot a multi-VM cybersecurity lab on Proxmox VE behind a pfSense-segmented network. The environment centralizes Windows and Linux systems, Wazuh security monitoring, Active Directory services, File Integrity Monitoring, privileged-group monitoring, and controlled SOC-style event investigations.

Key Accomplishments

  • Diagnosed and repaired a Proxmox connectivity failure involving the live Linux bridge.
  • Validated gateway, Internet, and VM-to-VM connectivity across the lab.
  • Enrolled Windows, Windows Server, Ubuntu, and Kali endpoints into Wazuh.
  • Configured real-time Windows File Integrity Monitoring and verified file creation and checksum-change alerts.
  • Validated Active Directory authentication and account-management events in Wazuh.
  • Validated privileged Domain Admins membership monitoring using a controlled test account.
  • Verified Event ID 4728 when the account was added to Domain Admins and Event ID 4729 when it was removed.
  • Created a reusable Windows Server / AD security-event monitoring view.
  • Performed a mini SOC investigation correlating repeated failed logons with an account lockout.

Privileged Domain Admins Monitoring

A controlled account named PrivTest was temporarily added to the Domain Admins group and then removed. Wazuh captured both membership changes and exposed the changed member, the privileged target group, the administrative actor, and the domain controller that recorded the event.

4728: PrivTest added to Domain Admins
4729: PrivTest removed from Domain Admins

This demonstrates centralized visibility into high-impact Active Directory privilege changes.

SOC Investigation Example

A controlled test account was configured with a temporary lockout policy. Three failed authentication attempts generated Event ID 4625 events followed by Event ID 4740. Wazuh was used to review the target account, timestamps, source system, rule IDs, and severity.

Assessment: Authorized lab activity. No malicious activity identified.
